# Plant Tracker 1.0.6

## Store Summary
This update improves launch-screen polish and local photo reliability while keeping your care timeline and in-app guidance up to date.

## New Features
- Added a one-command TestFlight release flow that regenerates in-app update notes before shipping.
- Expanded App Guide navigation with clearer horizontal tab affordances and dynamic arrows.

## Bug Fixes
- Fixed splash-screen color mismatch so the logo no longer appears inside a visible square at launch.
- Improved local plant-photo URI recovery across iOS/TestFlight updates when app container paths change.
- Improved update-note generation stability by preferring explicit New Features/Bug Fixes sections in release notes.

## Full Release Notes
Version 1.0.6 focuses on polish and release reliability. The app now launches with a cleaner splash appearance, retains local images more reliably after updates, and uses a stronger release-note pipeline so in-app update screens stay accurate for each TestFlight build.

## Alternate Summary
Plant Tracker 1.0.6 fixes splash-screen visuals, improves photo persistence after updates, and strengthens release/update note automation.
